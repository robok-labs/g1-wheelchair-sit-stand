# tasks

`tracking_env_cfg_skeleton.py` は unitree_rl_lab の Mimic タスク(`ManagerBasedRLEnvCfg`)を車いす用に組んだ構成の骨組みです。報酬の重み・std・しきい値・外乱の範囲は学習に用いた値を公開しません(骨組みの W / P はプレースホルダ)。接触ペナルティの対象リンクの正規表現は残してあります。段階ごとに追加した項の構成は下の報酬表に示します。

`tracking_env_cfg_formal_seat_skeleton.py` と `formal_seat_mdp.py` は座位目標の導入段階の骨組みと、報酬・終了・補助制御の実装です(「座位目標の導入段階」の節)。

## シーン配置

| 項目 | 値 |
|---|---|
| 地面 | 平面 |
| 車いす | USD(`wheelchair_up`)、`pos = (-0.03, 0, 0)`、`rot = Rx90`(クォータニオン `(0.70711, 0.70711, 0, 0)`)、`scale = 0.0086` |
| ロボット | G1 29dof(unitree_rl_lab の Mimic 用設定) |
| 接触センサ | ロボット全リンク |

参照モーションの座標系は、着座向き +X、着座時の骨盤が原点です。

## 観測

- policy: 参照モーションのコマンド、アンカー姿勢誤差、角速度、関節位置・速度(相対)、直前の行動(ノイズ付き)
- critic: 上に加えてアンカー位置、各ボディの位置・姿勢、線速度(ノイズなし)

## 終了条件

- タイムアウト
- アンカー高さ(z)の誤差がしきい値超
- アンカー姿勢の誤差がしきい値超
- 両足首・両手首の高さ(z)の誤差がしきい値超

## 学習の外乱

外乱の種類は次のとおり。範囲は段階ごとに異なり、値は公開しない。採用版は押しなしで、初期化ノイズを小さくし、摩擦の起動時ランダム化だけを残した。

- 初期状態のランダム化(位置、姿勢、関節)
- 床摩擦・関節デフォルト位置・胴体重心のランダム化
- 一定間隔の弱い押し外乱(採用版では無効)

## 報酬

段階名はレポートと同じ。Stage 1 は 幾何補正段階 → 接触・外乱条件の追加段階 → 固定開始・位置追従の導入段階 → 座位目標の導入段階。Stage 2 は 斜め進入版(本リポジトリのスクリプト)と、正面接近版・退去(手続き生成。参照生成コードは未同梱)。

| 報酬項 | 関数 | 式 | 適用 |
|---|---|---|---|
| 関節加速度 | `joint_acc_l2` | Σ q̈² | 全段階 |
| 関節トルク | `joint_torques_l2` | Σ τ² | 全段階 |
| 行動の変化 | `action_rate_l2` | Σ (a_t − a_{t−1})² | 全段階 |
| 関節の可動域超過 | `joint_pos_limits` | 超過量の和 | 全段階 |
| 胴体位置の追従 | `motion_global_anchor_position_error_exp` | exp(−‖Δp‖²/σ²) | 全段階 |
| 胴体姿勢の追従 | `motion_global_anchor_orientation_error_exp` | exp(−Δθ²/σ²) | 全段階 |
| 部位位置の追従 | `motion_relative_body_position_error_exp` | exp(−mean‖Δp_b‖²/σ²) | 全段階 |
| 部位姿勢の追従 | `motion_relative_body_orientation_error_exp` | exp(−mean Δθ_b²/σ²) | 全段階 |
| 部位線速度の追従 | `motion_global_body_linear_velocity_error_exp` | exp(−mean‖Δv_b‖²/σ²) | 全段階 |
| 部位角速度の追従 | `motion_global_body_angular_velocity_error_exp` | exp(−mean‖Δω_b‖²/σ²) | 全段階 |
| 不要な接触 | `undesired_contacts` | 足首・手首・骨盤・股以外で接触力がしきい値を超えた部位数 | 全段階 |
| 足と車いすの近接 | `foot_chair_penalty` | clip((m − d_f)/m, 0, 1)。m は余裕 | 全段階 |
| 上体と肘掛け・背もたれの近接 | `upper_chair_penalty` | clip((m − d_u)/m, 0, 1)。m は余裕 | 接触・外乱条件の追加段階以降 |
| 骨盤 xy の位置追従(車いす座標系) | `root_xy_error_squared` | ‖p_xy − p*_xy‖² | 固定開始・位置追従の導入段階以降、Stage 2 |
| 骨盤の座位目標 | (自作) | min((‖Δp_xy‖/a)² + (Δz/b)², 上限) | 座位目標の導入段階、座位窓 |
| 上体の座位目標 | (自作) | min((θ_pitch/c)², 上限) + min((θ_yaw/c)², 上限) | 座位目標の導入段階、座位窓 |
| 肩の左右差 | (自作) | min((Δx_shoulder/d)², 上限) | 座位目標の導入段階、座位窓 |
| 腕関節の追従 | (自作) | c(t)·mean_j (q_j − q*_j)²(腕 14 関節)、c は座位窓で 1、動作中で 1 未満 | 座位目標の導入段階、全相 |
| 手首の位置(腿座標系) | (自作) | mean ‖w − w*‖(hip_roll_link 座標系) | 座位目標の導入段階、座位窓 |
| 着座位置の目標(斜め進入版) | `seated_xy_error_squared` | s(t)‖p_xy − p*_xy‖²、25 frame で立ち上げ | Stage 2 斜め進入版の着座、着座相 |
| 足の交差 | (自作) | clip((m − s)/m, 0, 1)、s は体の向きに対する左右足の横間隔 | Stage 2 正面接近版・退去 |
| 接近の終端姿勢 | (自作) | s(t)‖p − p*‖²(骨盤 3 次元)、50 frame で立ち上げ | Stage 2 正面接近版、終端相 |
| 接近の終端の上体 | (自作) | s(t)Δθ_torso² | Stage 2 正面接近版、終端相 |
| 退去終端の高さ | `terminal_height_error_squared` | s(t)(z − z*)²、保持相の 10 step で立ち上げ | Stage 2 退去(斜め進入版・退去とも)、保持相 |

d_f は足の衝突球と全部材の最小距離、d_u は上体のリンクを包む箱と肘掛け・背もたれの分離距離の下界。重み・σ・余裕 m・しきい値は非公開。学習時の終了は、足と部材の距離が極小、骨盤 xy の誤差が大(固定開始・位置追従の導入段階以降)を上の終了条件に加える。 座位窓は 2 種類ある。座位の静止窓(起立 frame [0, 50)、着座 [440, 540))で骨盤・上体・肩の罰と終了(骨盤と式典座位の距離が大)、腕込み判定を用いる。接続区間を含む座位窓(起立 [0, 100)、着座 [390, 540))で腕関節と手首の罰を係数 1.0 とする。起立には補助制御(開始窓 [0, 100) で腕 14 関節の PD 目標を 0.3 × 方策 + 0.7 × 参照角、末尾 15 frame で smoothstep 解除、学習・再生とも)を併用した。座位目標の導入段階の項と補助制御は `formal_seat_mdp.py` に含む。それ以外の(自作)の関数(足・上体と車いすの距離罰、骨盤 xy の罰など)は含まない。

## 座位目標の導入段階(式典座位・自然な腕・補助制御)

着座の終端と起立の開始を、シミュレータで実測した「式典座位」(目標姿勢: 足裏接地・上体鉛直・腰 0・手は腿の上。`motions/formal_seat_pose.json`)に置く段階。学習結果では手は腿の上方に留まり、腿との接触は達成しなかった。参照の生成は `motions/formal_seat.py`、報酬・終了・補助制御は `tasks/formal_seat_mdp.py`、cfg は `tasks/tracking_env_cfg_formal_seat_skeleton.py`、判定は `scripts/eval_formal_seat.py`。

### 参照(`motions/formal_seat.py`)

| 区間 | 着座(540 frame) | 起立(490 frame) |
|---|---|---|
| 直立の静止 | 先頭 50 | 末尾 50 |
| 直立 <-> 人の動作のブレンド | 50 | 50 |
| 人の動作 | 290 | 290 |
| 人の動作 <-> 式典座位のブレンド | 50 | 50 |
| 式典座位の静止 | 末尾 100 | 先頭 50 |

- 全 frame を左右対称にした(骨盤 y・yaw・roll = 0、腰 yaw/roll = 0、腕は左右平均)。脚は IK で解き直し、足は平置きのまま。
- 式典座位は関節の目標角を使い、骨盤は目標の位置・単位姿勢に置く。手首は x, z を保って |y| を内側へ寄せ、肘掛けの箱から離した。
- 自然な腕(`naturalize_arms`): 動作区間の腕を直立の体側 <-> 式典座位の間で骨盤高さの進捗に沿って補間し、人の肩 pitch・肘の動きを一部だけ重ねる。肩の前方挙上、肘の角度、関節速度には上限を設ける(値は非公開)。人の腕が前へ大きく伸びる動作をそのまま追従させない。

### 報酬と終了(`formal_seat_mdp.py`)

骨盤・上体・肩の項は座位の静止窓(着座 frame [440, 540)、起立 [0, 50))だけで働き、起立・着座の動作中の前傾は妨げない。重みは非公開。

- 骨盤、上体、肩の左右差(座位窓)。座位窓で骨盤が式典座位から大きく離れたら終了。
- 腕 14 関節の追従 mean (q − q*)²(上限なし)。座位窓(着座 [390, 540)、起立 [0, 100))で係数 1、動作中は 1 未満。exp 型の追従項は誤差が大きいと勾配が消えたため、二乗平均にした。
- 手首の位置: 腿座標系での参照との距離(接続区間を含む座位窓: 着座 [390, 540)、起立 [0, 100))。
- 上体と肘掛けの近接罰の余裕を、式典座位の腕と肘掛けの距離(値は非公開)より小さくし、目標姿勢で罰が出ないようにした。

### 補助制御(起立のみ)

環境変数 `ARM_PD_BLEND=0.7` で有効。起立の開始窓 [0, 100) frame で、腕 14 関節の PD 目標を 0.3 × 方策 + 0.7 × 参照角にする。末尾 15 frame は smoothstep で 0 へ戻し、窓の外では方策だけが腕を動かす。学習と再生の両方に適用する。着座は補助なし。

起立の結果は、模倣 RL 方策と開始座位の腕参照補助を組み合わせた制御系の性能であり、方策単独による腕姿勢の獲得を示すものではない。補助なしでは開始座位で腕を前に伸ばした。

### 腕込み判定(`eval_formal_seat.py`)

結果を見た後に追加した判定。座位の静止窓(着座は [440, 540) の最後の 50 step、起立は [0, 50))で次をすべて満たすと合格。

- 骨盤が式典座位から xy 3 cm 以内・z 2 cm 以内(窓平均)
- 上体の傾き(pitch)と腰ヨーがともに 5° 未満(窓平均)
- 肩の左右差(x)が 3 cm 未満(窓平均)
- 手首が全 step・左右とも z 0.62 m 未満で、肘掛けの x 範囲の外か |y| < 0.135 m
- 腕と肘掛けの箱近似の距離が正。箱は保守的な近似で、物理接触の判定ではない。上体形状は含まないため、距離は CSV の列で渡す

## Stage 2: 歩いて接近 -> 転回 -> 着座 / 起立 -> 前進 -> 退去(初期の試行は転回あり)

以下は斜め進入版の骨組みと仕様。この版は厳格判定で 0/10 だった(トップの README の結果)。表中の「改善版」は斜め進入版の追加学習を指す。

`tracking_env_cfg_stage2_skeleton.py` が骨組み。Stage 1 の骨組みを継承し、変える点だけを書いている。報酬の重みとしきい値は非公開。`stage2_mdp` の自作関数と `validation_motion.json` は本リポジトリに含まない(下表に仕様を書く)。

### タスク構成

着座と起立で別タスクを登録し、参照クリップ(`motions/stage2_motion.py` の出力)だけを差し替える。

| 項目 | 内容 |
|---|---|
| gym id の形 | `Unitree-G1-29dof-Mimic-Wheelchair-Approach-Sit-Skeleton`、`Unitree-G1-29dof-Mimic-Wheelchair-Stand-Depart-Skeleton` |
| コマンド | Stage 1 のコマンドを継承。参照は可変長で周回させず、末尾は 50 step 保持して終了(クリップ完了でタイムアウト)。制御周期 0.02 s・参照 50 Hz を起動時に検査 |
| 静止開始率 | リセットされた env のうち 一定割合以上を必ずフレーム 0(静止)から開始させる。残りは Stage 1 同様の適応サンプリング |
| 初期化ノイズ | Stage 1 より縮小(値は非公開)。押し外乱・重心/既定姿勢のランダム化は無効 |
| シーン | env 間隔 4 m(歩行分)、ソフト関節制限率 0.98(参照の転回姿勢が 0.90 では切れるため) |

### 追加した罰と終了

| 項目 | 内容 |
|---|---|
| 世界座標 xy 罰と終了 | 車いす固定の世界座標で、骨盤 xy と参照の差の二乗を罰する。初期化ノイズで参照側が動かないよう、env 原点を足した参照を使う。差が大きいと終了(しきい値は非公開) |
| 着座相の骨盤 xy 目標罰(歩行統合版の改善版、着座のみ) | 着座相の開始フレームから 25 frame かけて重みを 0 から 1 へ立ち上げ、骨盤 xy と座面付近の目標の差の二乗を罰する |
| 退去終端の高さ罰(歩行統合版の改善版、起立のみ) | 保持相に入ってから 10 step かけて重みを立ち上げ、骨盤 z と参照 z の差の二乗を罰する |
| 足・上体と車いすの距離 | 足の外形ボックスは余裕の外から罰し、極小距離で終了。上体(肘掛け・背もたれ)も余裕の外から罰する。余裕・しきい値は非公開。全相で有効 |
| 終了条件の変更 | 高さ偏差の終了対象を足首のみにする(手首は外す) |

改善版は、既存方策の評価で着座の骨盤が座面中心より約 10 cm 前方にずれ、退去の終端高さが参照より 3〜4 cm 低かったため、この 2 つの罰だけを足して +800 iter 追加学習する構成。参照クリップ・観測・車いすは変えない。

### 再生

再生用 cfg は 1 env、常にフレーム 0 から、初期化ノイズなし、クリップ完了で終わらない設定。録画した軌跡の判定は `scripts/eval_stage2.py` を使う。
